    Class TypographistRules<TLocale>

    Supplies locale rules from Knuth–Liang and Khristov datasets, or from a subclass's own storage. Typographist calls compile once per registration with its configured useFast flag.

    Example

    const rules = new TypographistRules({
      standard: {
        locale: 'en', alphabet: 'abcd', leftMin: 1, rightMin: 1, patterns: ['a1b'],
      },
      fast: {
        locale: 'en', alphabet: 'abcd', leftMin: 1, rightMin: 1,
        vowels: 'a', consonants: 'bcd', specialLetters: '',
      },
    });
    rules.compile(true); // Returns Khristov classifications.
